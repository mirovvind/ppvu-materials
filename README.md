# Учебные материалы к практическим работам

Дисциплина «Прикладное программирование на языке высокого уровня»,
РОСБИОТЕХ, кафедра АСУБП.

- pw1/draft.py — учебный файл с нарушениями оформления (работа 1, п. 4.6);
- pw2/ai_publication.py — код ИИ-ассистента для разбора (работа 2, п. 4.2);
- pw2/data/crossref_sample.json — учебная выгрузка Crossref (30 записей,
  сведения о публикациях вымышлены);
- pw2/starter/ — заготовки модулей для базового уровня работы 2;
- checks/pw2_check.py — самопроверка работы 2: uv run python -m checks.pw2_check
- pw3/starter/ — модули этапов конвейера и заготовки тестов (работа 3);
- pw3/configs/ — конфигурации критериев с недопустимыми значениями;
- pw3/data/registry.csv — учебный справочник изданий (сведения вымышлены,
  уровни изданий не соответствуют ЕГПНИ);
- pw3/demo/ — программы для опытов в каталоге sandbox (работа 3);
- checks/pw3_check.py — самопроверка работы 3: uv run python -m checks.pw3_check

Порядок работы с материалами приведён в методических указаниях.
